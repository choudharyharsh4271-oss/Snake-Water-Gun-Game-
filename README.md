# 🐍 Snake Water Gun Game

A fun, interactive command-line interface (CLI) game written in Python based on the popular **Snake - Water - Gun** rules (a variant of Rock-Paper-Scissors).

---

## 🎮 Game Rules
- **Snake (`s`) vs Water (`w`):** Snake drinks Water ➔ **Snake Wins**
- **Water (`w`) vs Gun (`g`):** Water douses/ruins Gun ➔ **Water Wins**
- **Gun (`g`) vs Snake (`s`):** Gun shoots Snake ➔ **Gun Wins**
- **Same choice:** It's a **Tie**!

---

## ✨ Features
- 🔄 **Customizable Rounds:** Choose how many rounds you want to play.
- 🤖 **Randomized AI:** Play against the computer using Python's `random` module.
- 📊 **Real-Time Score Tracking:** Keeps track of player and computer scores across all rounds.
- 🏆 **Final Winner Announcement:** Calculates overall victory based on total scores at the end.
